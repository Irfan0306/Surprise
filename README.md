# Sir Ji Birthday Surprise ❤️

A romantic, mobile-friendly birthday surprise website with balloon popping, a candle-blowing moment, your photos, a love letter, and the final gift clue.

## Files

- `index.html` — complete website (HTML, CSS, and JavaScript)
- `assets/` — all 8 photos used by the website

## Publish with GitHub Pages

1. Sign in to GitHub and create a **New repository**.
2. Give it a name such as `sir-ji-birthday`.
3. If you want the website publicly accessible, choose **Public**. (GitHub Pages on a free personal account generally requires a public repository.)
4. Upload `index.html` and the entire `assets` folder, keeping the folder structure unchanged. You can upload the ZIP contents after extracting it on your phone/computer.
5. In the repository, open **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select branch **main** and folder **/ (root)**, then press **Save**.
8. Wait a few minutes. Your website address will look like `https://YOUR-USERNAME.github.io/sir-ji-birthday/`.

## Important privacy note

A normal GitHub Pages site is public: anyone who has the link may view the website, and a public repository lets people browse/download its code and photos. Do not upload intimate or private photos if you are not comfortable with that. A hard-to-guess URL is not password protection. For a truly private surprise, use a hosting service that supports password protection or share the site privately as a file.

## Test it

Open `index.html` in a browser. Keep the `assets` folder next to it so the photos load.
